## 一、本轮实际修掉的问题

### 1. 打卡日历「漏签」格子对比度不达标（文字 + 边框，唯一真实 AA 违规）

`.cal-day.cal-missed` 同时有两处不达标：

| 元素 | 令牌 | 修复前 | 修复后 |
|---|---|---|---|
| 文字（12px，需 4.5:1） | `--coral` → `--coral-text` | 白底 2.31:1 | **5.45:1** / 深色 7.30:1 |
| 虚线边框（非文本 UI 边界，需 3:1） | `--coral` → `--coral-text` | 白底 2.31:1 | **5.45:1** / 深色 7.30:1 |

`--coral-text`（#B04A28）是设计系统里专为文字场景准备的珊瑚色，深色主题下它指向
`--coral`（#FF9A76），两套主题都稳。实测落地值：浅色 `rgb(176,74,40)` / 深色 `rgb(255,154,118)`。

**同时改了图例色块** `.cal-dot-missed`：CSS 1724 行明确写着「图例与格子必须一致」，
只改格子会让图例不再代表格子。两处现已同色（实测 `legendBorder` 与格子 `border` 一致）。

视觉复核：改色后漏签格为深砖红虚线 + 同色数字，两套主题下均可读且不过重（已截图确认）。

### 2. 17 个表单控件缺可访问名（`label` 少了 `for`）

页面里有一批写成 `<label>词库：</label><select id="x">` 的控件：
label 既没有 `for`、也没有包裹控件 → 屏幕阅读器读到的是无名下拉/滑块。

已补 `for` 的 17 处：

- 词库类 4：`spelling-category` / `speak-category` / `listening-category` / `pk-category`
- 其余 11：`word-category`、`spelling-mode`、`mistake-source`、`mt-source`、
  `phonetic-category`、`grammar-type`、`grammar-difficulty`、`reading-select`、
  `reading-difficulty`、`listening-mode`、`fav-source`
- 设置页 2：`custom-color-input`（取色器）、`bg-opacity-slider`（背景透明度）

已校验：全站残留无关联 label = 0，无重复 id，所有 `for` 指向的 id 均存在。

> **为什么上一轮没报出来**：旧探测器拿 `innerText` 当可访问名，而 `<select>` 的
> `innerText` 返回的是**当前选中项的文本**。选项一旦被 JS 填充成「全部来源」「综合练习」
> 这类非空文本，就会被误判成"有名字"，把 13 个真实缺陷全部掩盖掉。
> 词库类那 4 个只是因为首选项是空文本才露了出来。

## 二、审计脚本本身的 3 处误报修复（`scripts/ui-audit.mjs`）

这一轮真正的问题是**探测器在误报**：修完产品缺陷后重跑，仍有 18 条记录，
逐条核实后确认全是假阳性。已按根因修掉，否则以后每次复跑都会复现同样的噪声。

| 根因 | 表现 | 修法 |
|---|---|---|
| `innerText` 对 `<input>` 恒为空、对 `<select>` 返回选项文本 | 8 个有 `<label>` 包裹的开关全被报成无名；13 个真无名下拉反被掩盖 | 字段类改走 `el.labels` 关联取名；文本类用 `textContent` 兜底（字段类不能兜底，否则又掩盖） |
| 未过滤「有布局盒但没渲染」的子树 | 离屏抽屉里的 8 个 AI 设置项、折叠 `<details>` 里的 1 个空态按钮、toast 入场动画途中的 1 个按钮 | 跳过 `visibility:hidden` 的与 `details:not([open])` 内的 |
| 「越界」不区分裁切来源 | AI 建议 chips 横滑条 3 项、toast 停在 `translateX(120%)` 时 1 项 | 横向滚动容器内的元素与 `.toast` 内的元素不参与越界判定 |

核实证据（不是靠猜）：
- 拼写页那条越界单独复现 **0 次**、按原页面顺序复现 0 次，抓 DOM 后确认是
  `class="toast-close"` 的按钮——它静止时 `right=1408`，被记录时 `right=1711`，
  差值 303px 正好是 `.toast` 的 `translateX(120%)` 位移量。
- 设置页那条无名按钮，抓 DOM 确认是折叠的 `details#report-trend` 里
  「去背单词」按钮，`innerText` 因未渲染而为空。
