# Android Adaptation Design — 闻道 MindSpeak

> Status: Approved | Date: 2026-08-20 | Scope: All 6 modules (P0-P3)

## Overview

Comprehensive Android adaptation for the MindSpeak English learning app. The app currently runs as a PWA (works on Android browsers) and as a Tauri desktop app. This design adds a native Android APK via Capacitor 6 with a bundled lightweight server, enhanced offline caching, Android-specific interactions, and foldable/tablet support.

## Constraints

- Keep zero framework dependency (Capacitor is a packaging shell only)
- Maintain backward compatibility with existing PWA and Tauri desktop
- Don't break existing CSS adaptations (mobile.css, 536 lines)
- Reuse existing `mindspeak-keystore.p12` for APK signing
- All new features must have Vitest tests
- Follow existing code style (var, IIFE modules, no comments unless asked)

## Architecture

### Build Pipeline

```
npm run build          # build.js → dist/
npx cap sync android   # Push dist/ into android/app/src/main/assets/public/
cd android && gradlew  # Build APK
```

Capacitor loads the web app from `android/app/src/main/assets/public/` (same as dist/). The NanoHTTPD server plugin starts in the native layer and bridges to the WebView via `window.Capacitor.Plugins.HttpServer`.

### Module Decomposition

| Module | Priority | Native Code | Files |
|--------|----------|-------------|-------|
| Capacitor Config | P0 | Config only | capacitor.config.ts, package.json |
| NanoHTTPD Server | P0 | Java/Kotlin | android/app/src/main/java/.../*.java |
| Back Button Nav | P1 | JS injection | js/app.js |
| Enhanced SW | P1 | JS only | sw.js, build.js |
| Local Notifications | P2 | Capacitor plugin | js/notifications.js |
| Foldable/Tablet | P2 | CSS + JS | css/mobile.css, js/app.js |
| UI Adaptation | P3 | CSS + JS | css/mobile.css, js/app.js |

## Module 2: NanoHTTPD Server Plugin

### Purpose

Bundle a lightweight HTTP server inside the Android APK so the WebView can call `/api/tts`, `/api/log`, and `/api/health` without an external server.

### Architecture

```
WebView (JS)  ←→  Capacitor Bridge  ←→  HttpServerPlugin.java  ←→  NanoHTTPDServer.java
                    (Plugin API)           (Capacitor plugin)        (127.0.0.1:3000)
```

### Native Files

**HttpServerPlugin.java** — Capacitor plugin bridge:
- Extends `Plugin`
- `@PluginMethod startServer()` — starts NanoHTTPD
- `@PluginMethod stopServer()` — stops NanoHTTPD
- `@PluginMethod isRunning()` — returns server status

**NanoHTTPDServer.java** — Embedded HTTP server:
- Extends `NanoHTTPD` (org.nanohttpd:nanohttpd:2.3.1)
- Routes: `/api/health`, `/api/tts`, `/api/log`
- TTS: Wraps Android's `TextToSpeech` engine via the same `/api/tts` endpoint format as the desktop server, so existing client-side TTS code (`_speakRemoteFallback`) works unchanged. The NanoHTTPD server translates the request into Android TTS calls and returns audio or triggers playback via the Capacitor bridge. This avoids duplicating the local SAPI fallback — `_speakLocal` in app.js still handles the non-server path.
- Log: Writes to `android.util.Log` + local file

**MindSpeakBridge.java** — WebView ↔ Server communication:
- Provides `getLocalIpAddress()` for WebView to discover server
- Handles CORS headers for localhost requests

### JS Integration

In `js/app.js`, modify `_probeServer`:

```javascript
// Check if native server is available
var _nativeServerAvailable = !!(window.Capacitor && window.Capacitor.Plugins && window.Capacitor.Plugins.HttpServer);

if (_isAndroid || _isCap || _isCapGlobal) {
  if (_nativeServerAvailable) {
    // Native server is running, probe it
    fetch(_serverBase + '/api/health', { method: 'GET', signal: AbortSignal.timeout(3000) })
      .then(function(r) { ... })
      .catch(function() { ... });
  } else {
    // No native server, mark server as down
    self._serverDown = true;
  }
}
```

## Module 3: Android Back Button / Gesture Navigation

### Priority Chain

When the Android back button is pressed:

1. **Sidebar open** → close sidebar
2. **Modal/dialog open** → close it
3. **History available** (`history.length > 1`) → `history.back()`
4. **Nothing to go back** → show "退出确认" dialog (2s timeout, auto-dismiss)

### JS Implementation

In `js/app.js`, add `_initAndroidBackHandler`:

```javascript
_initAndroidBackHandler: function() {
  if (!window.Capacitor || !window.Capacitor.Plugins || !window.Capacitor.Plugins.App) return;
  var self = this;
  window.Capacitor.Plugins.App.addListener('backButton', function() {
    // 1. Sidebar
    var sidebar = document.getElementById('sidebar');
    if (sidebar && sidebar.classList.contains('open')) {
      sidebar.classList.remove('open');
      return;
    }
    // 2. Modal
    var modal = document.querySelector('.modal-overlay.active');
    if (modal) {
      modal.classList.remove('active');
      return;
    }
    // 3. History
    if (window.history.length > 1) {
      window.history.back();
      return;
    }
    // 4. Exit confirmation
    self._showExitConfirm();
  });
},
_showExitConfirm: function() {
  // Toast "再按一次退出" with 2s timeout
  Toast.info('再按一次退出');
  this._exitTimeout = setTimeout(function() {
    self._exitTimeout = null;
  }, 2000);
}
```

### Files

- Modified: `js/app.js` (add `_initAndroidBackHandler`, `_showExitConfirm`)

## Module 4: Enhanced Service Worker

### Current State

SW caches only app shell (JS, CSS, assets, index.html). Strategy: cache-first for shell, network-first for API.

### Enhancements

1. **Data file caching** — Cache all `data/*.json` files for offline vocabulary access
2. **Stale-while-revalidate** for `js/bundle.js` — Serve cached version immediately, update in background
3. **Font cache** — Cache Google Fonts (Noto Sans SC, Inter) for offline Chinese/English rendering
4. **Offline fallback** — Show cached `index.html` when network unavailable

### Updated Cache Manifest


### Updated Fetch Strategy

```javascript
// Stale-while-revalidate for bundle.js
if (url.pathname.endsWith('bundle.js')) {
  e.respondWith(
    caches.open(CACHE).then(function(cache) {
      return cache.match(req).then(function(cached) {
        var networkFetch = fetch(req).then(function(res) {
          if (res.ok) cache.put(req, res.clone());
          return res;
        }).catch(function() { return cached; });
        return cached || networkFetch;
      });
    })
  );
  return;
}
```

## Module 6: Foldable Screen / Tablet Responsive

### Breakpoints

| Device | Width | Layout |
|--------|-------|--------|
| Phone | < 600px | Single column (current) |
| Tablet portrait | 600-839px | Wider grid (3-col word grid) |
| Foldable unfolded / Tablet landscape | ≥ 840px | Dual-column (sidebar + content) |

### CSS Approach

```css
/* Tablet portrait — wider word grid */
@media (min-width: 600px) and (max-width: 839px) and (pointer: coarse) {
  .word-grid { grid-template-columns: repeat(3, 1fr); }
  .stat-cards { grid-template-columns: repeat(3, 1fr); }
}

/* Foldable unfolded / Tablet landscape — dual-column */
@media (min-width: 840px) and (pointer: coarse) {
  .app-layout {
    display: grid;
    grid-template-columns: 280px 1fr;
    grid-template-rows: 1fr;
  }
  .sidebar {
    position: static;
    transform: none;
    box-shadow: none;
  }
  .content {
    overflow-y: auto;
    -webkit-overflow-scrolling: touch;
  }
}
```

### JS Approach

```javascript
_initFoldableLayout: function() {
  var mql = window.matchMedia('(min-width: 840px) and (pointer: coarse)');
  var self = this;
  function update(e) {
    document.documentElement.classList.toggle('dual-column', e.matches);
  }
  update(mql);
  mql.addEventListener('change', update);
}
```

## Known Limitations

1. **NanoHTTPD size** — Adds ~200KB to APK. Acceptable for feature completeness.
2. **Server startup time** — NanoHTTPD takes ~200ms to start. App should show splash screen.
3. **Battery impact** — NanoHTTPD runs as long as app is open. Consider stopping on background.
4. **Android version** — Capacitor 6 requires Android API 22+ (Android 5.1+).
5. **Keystore security** — `mindspeak-keystore.p12` is in repo root. For production, move to CI/CD secrets.
6. **Testing native code** — Java/Kotlin tests require Android emulator. JS tests mock the native bridge.

## Success Criteria

- APK builds successfully with `npm run android:build`
- APK installs and runs on Android 5.1+ devices
- TTS works via embedded NanoHTTPD server
- Back button navigates correctly through app
- App works offline (cached content accessible)
- Notifications fire at scheduled times
- Layout adapts to foldable unfolded state
- All 7 test files pass in Vitest
